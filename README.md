# What is Pars-Legacy?
A Debian-based Linux distribution project aimed at reviving the legendary old Pardus aesthetic with modern stability.

### What's in this release?

* **Pardus 2011 Plymouth (Boot Screen):** (Note: Does not show up on the Live USB)
* **Classic Themes:** Oxygen and Milky themes from the 2009-2011 Pardus era.
* **Katana Desktop:** The KDE 4 interface has been brought back to life using the Katana Desktop Environment, which is a KDE 4 fork (see: [GitHub - fluxer/katana-debian: Debian packages for Katana Desktop Environment](https://github.com/fluxer/katana-debian))

What is Pars Legacy?
Pars Legacy is a community project that collects vintage Pardus interfaces and applies them to modern desktop environments. Our goal is to provide a retro Linux desktop experience as a modern distribution, compatible with both contemporary hardware and older devices.

What does Pars Legacy offer?
Up-to-date Base: A modern Linux system based on Debian.

Nostalgic UI: The classic retro interface of the original Pardus.

Low Resource Usage: (Minimum: 500MHz CPU / 512MB RAM / 6GB Disk / x64 Architecture)

What's in this 1.0 Version?
Q4OS Toolset: Features Q4OS’s unique Debian package installer.

Retro Pardus 1.0 Interface: The UI has been painstakingly recreated using TDE (Trinity Desktop Environment), a fork of KDE 3, to look exactly like the original.

Pre-installed Software: Includes VLC, Firefox, LibreOffice, and other essential internet and office applications.
